## Functional MVP scope

Run Server, Coach and browser on the learner's one MacBook through the shared loopback default. No application authentication, tokens, Keychain integration, Tailscale or remote hosting is required. Use one selected Codex adapter with the normal user subscription login and repository workspace. Retain existing Claude code without requiring Claude integration or qualification for this MVP. Never switch providers automatically or enable paid API execution.

The full [content rules](../decision-targeted-drilling.md), [learning policy](../decision-core-trainer.md), [recording rules](../decision-recording-and-comparison.md) and [personal preferences](../decision-personal-preferences.md) govern acceptance. Fixed phrases alone are insufficient. The MVP includes:

- Fixed wording, variable slots/frames, accepted alternatives, situation prompts and partner turns, prompt rotation and answer-leak prevention; words as one sense with two or three comprehensible contexts or translated chunks, sense cues and applicable grammatical forms.
- The specified multilingual card/help/translation preferences, including English, German and Serbian preparation. Resolve required missing preferences through a separately authorized profile update before dependent preparation. Never silently replace a chosen card/help language or infer unknown meaning.
- Preferred responses with separate target histories, bounded duplicate/confusable matching across entries, directed introduction dependencies and their later-learning-day/unavailable-prerequisite rules. Dialogue runs, partner-turn cards and declared cross-target exposure obey their distinct evidence rules.
- Ungraded first study, later independent recall, reveal/comparison, honest self-rating, scheduled due return, supported repetition and optional recording with every take retained. Include the specified first spaced check, hint-failure exception, repair bounds and all support/lifecycle/technical exclusions. A first-study demo is only an internal checkpoint.
- Delete/Removed-items Restore, preferred-target selection and atomic Recreate card with visible outcome, preserving identity/history when compatible and invalidating stale evidence bindings. These are required ways to stop and repair defective material; broader management screens are deferred.

Coach's main window contains only the inbox drop area, simple Server database statistics and a settings button. All settings live in a separate dialog. Deliberate paste/drop automatically infers defensible preparation details, preserves input and reports processing/errors and confirmed additions inline. No routine questions, Connect/Load/Choose pipeline or prebuilt lesson is part of ordinary intake. The frontend drop space and external inbox use the same durable contract. Text-only input must produce real reference speech; supplied valid audio is optional and preserved, while invalid supplied audio is rejected rather than replaced.

Use one acceptable primary speech configuration per required language, with exact input/voice/locale/cache identity and listening acceptance. A single English voice cannot satisfy multilingual content. Fallback voices and their qualification are deferred; no new macOS-only speech dependency is required. Publish only verified reference bytes before practice readiness.
