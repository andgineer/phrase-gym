## Finding: [P2] A response-body transport failure leaves new practice enabled

**Location:** `frontend/src/api.ts:48` (the successful response's body is read outside the connection-failure catch at lines 30–39). Related admission path: `frontend/src/composables/usePracticeSession.ts:127–137` and `frontend/src/composables/useServerRetry.ts:20–24`.

**Trigger:** Start a connected session, then trigger the normal foreground/online session refresh. Let `/api/v1/sessions/current` deliver HTTP 200 headers and an initial JSON byte, then sever its TCP response before the body finishes. This is a temporary transport failure during an ordinary authoritative read, with no offline practice or concurrent-device requirement.

**Observed in the real built client and real fixture server, in both Chromium and WebKit:** The failed read displays an error, but no `connection-required` screen appears. Recalled becomes enabled again on the retained card. Clicking it without Retry commits a new rating and advances the server cursor from 0 to 1. The selected session was not successfully reloaded through the recovery flow before this new learning command.

| Engine | Visible read error | Connection screen count | Rating enabled before retry | Server cursor after rating |
|---|---|---:|---|---|
| Chromium | `TypeError: Failed to fetch` | 0 | true | 0 → 1 |
| WebKit | `SyntaxError: The string did not match the expected pattern.` | 0 | true | 0 → 1 |

**Cause:** `fetch()` can resolve when response headers arrive; consuming its body can fail later. `api()` marks the server unavailable for a rejected initial fetch or a 5xx status, but propagates a rejected `response.json()` without setting that flag. `load()` catches the read failure and releases `restoring`; the foreground refresh caller ignores its false result. The existing session and attempt then satisfy practice admission. A visible read error alone does not block the controls.

**Supported-scope consequence:** New practice is admitted after a known server-read failure without the required retry and authoritative recovery. This violates the minimal online-only error/retry contract. It does not show speculative rating advancement or lost audio, and it does not require a health platform, probes, offline restoration, or an exhaustive failure matrix to fix. Extend the existing failure handling through response-body consumption and verify that this read failure blocks new practice until actual recovery succeeds, while preserving Stop/cancel.

The body-consumption placement existed at the P3 baseline, which had no P4 global connection admission contract. The finding concerns the incomplete new P4 failure boundary; it does not reopen P3 learning policy.

## Reproduction retained in this report

Start the existing disposable fixture on a separate port:

```sh
.venv/bin/python -m tests.browser_server --port 8953
```

Save the following disposable script outside the source tree and run it using the bundled Node executable. It resets only that fixture database. The proxy waits for Playwright to observe response headers before cutting the body; there is no arbitrary timing delay or API mock. It demonstrates the unwanted enabled control and actual committed rating, rather than asserting an invented offline guarantee. Initial harness iterations corrected accessible-name matching and WebKit's error-name difference; the final run below completed successfully for both engines.

```js
const http = require('node:http');
const { chromium, webkit, expect } = require('/Users/andrei_sorokin2/projects/phrase-gym/frontend/node_modules/@playwright/test');

(async () => {
  for (const [name, engine] of [['chromium', chromium], ['webkit', webkit]]) {
    await fetch('http://127.0.0.1:8953/_test/reset', {method:'POST'});
    await fetch('http://127.0.0.1:8953/api/v1/settings', {method:'PUT',headers:{'Content-Type':'application/json'},body:JSON.stringify({native_language:'ru',ui_language_mode:'learning'})});
    let armed = false, cutResponse;
    const server = http.createServer((req, res) => {
      const upstream = http.request({host:'127.0.0.1',port:8953,path:req.url,method:req.method,headers:req.headers}, response => {
        if (armed && req.url === '/api/v1/sessions/current') {
          armed = false;
          cutResponse = res;
          res.writeHead(200, {'Content-Type':'application/json','Transfer-Encoding':'chunked','Cache-Control':'no-store'});
          res.write('{');
          response.resume();
        } else {
          res.writeHead(response.statusCode, response.headers);
          response.pipe(res);
        }
      });
      upstream.on('error', () => res.destroy());
      req.pipe(upstream);
    });
    await new Promise(resolve => server.listen(0,'127.0.0.1',resolve));
    const origin = `http://127.0.0.1:${server.address().port}`;
    const browser = await engine.launch({headless:true});
    const page = await browser.newPage({baseURL:origin});
    try {
      await page.goto('/learn/en');
      await page.getByRole('button',{name:'Start session',exact:true}).click();
      await expect(page.getByRole('button',{name:'Recalled'})).toBeEnabled();
      const sessionId = page.url().split('/').pop();
      const received = page.waitForResponse(r => r.url() === origin+'/api/v1/sessions/current');
      armed = true;
      await page.evaluate(() => window.dispatchEvent(new Event('online')));
      await received;
      cutResponse.destroy();
      await expect(page.getByRole('alert').filter({hasText:/TypeError|SyntaxError/}).last()).toBeVisible();
      await expect(page.getByRole('button',{name:'Recalled'})).toBeEnabled();
      const before = await (await fetch(`http://127.0.0.1:8953/api/v1/sessions/${sessionId}`)).json();
      const evidence = {engine:name,error:await page.getByRole('alert').allTextContents(),connectionNoticeCount:await page.getByTestId('connection-required').count(),ratingEnabled:await page.getByRole('button',{name:'Recalled'}).isEnabled(),beforeCursor:before.cursor};
      await page.getByRole('button',{name:'Recalled'}).click();
      await expect(page.locator('.session-toolbar')).toContainText('2 / 3');
      const after = await (await fetch(`http://127.0.0.1:8953/api/v1/sessions/${sessionId}`)).json();
      console.log(JSON.stringify({...evidence,afterCursor:after.cursor}));
    } finally {
      await browser.close();
      await new Promise(resolve => server.close(resolve));
    }
  }
})().catch(error => {console.error(error);process.exitCode=1});
```
