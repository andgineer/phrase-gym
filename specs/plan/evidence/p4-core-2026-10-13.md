## Round-2 review corrections

Both findings in the [second fresh review](p4-review-2-2026-10-13.md) were accepted. Exclusive per-take ownership, atomic current-entry recovery, conditional byte-exact acknowledgement deletion and a separate namespace for new captures protect finalized audio from delayed readers and earlier app versions. Unleased legacy captures remain retained with explicit compatibility guidance. Support is bounded by the original response time; delayed dialogue script evidence uses its event occurrence time. Offline home compares event sequences only within the same session and restores the newer session by recency.

The ordered fix gate passed with Node 24.19.0: every hook passed, pyrefly reported zero errors, and **120 Python tests, 11 client tests and 222 browser checks** passed, with typecheck/build and both engines executed without skips. Six new capture-race browser scenarios and one session-recency scenario run in both engines; nine controlled-clock integration cases cover support and delayed script evidence. Browser instrumentation forwards the native LockManager through a stable manager reference in WebKit so the fault hooks exercise the intended races deterministically. No assertion was weakened or skipped. Actual-device acceptance remains open.
