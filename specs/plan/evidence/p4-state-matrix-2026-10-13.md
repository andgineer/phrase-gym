## Findings from applying the model

1. **R4 was still represented by inferred state in ordinary/repeated-target projection.** The committed reducer inferred help from `revealed` plus `finalized_at`/`presented_at`. A reveal six minutes earlier followed by a recent rating incorrectly refreshed support on a later repeated target. Direct execution of the committed `1063446` projection reproduced `supported=true`; the server's occurrence-time rule gives false. The audit replaced that inference with per-target `support_exposures`, derived by one server fact reader shared by support decisions and session snapshots. Client projection records actual queued exposure times and uses the same bounded window. Pack version 3 prevents old snapshots lacking these facts from claiming readiness. Acknowledged and queued help now receive real-browser repeated-target/reopen/foreground/reconciliation regressions.
2. **R5 admission was incomplete outside the main card.** Dialogue Rehearse, Isolate and partner playback omitted restoring/unavailable state; Download/Update also omitted restoration. Existing capture/card guards alone did not cover them. Explicit UI guards and serialized new-command admission now apply across these flows, with terminal capture observations still admitted for cleanup. A held real-server foreground read deterministically verifies introduction/detour/download controls, no new event sequence, and resumed interaction after release. Card effects moved into `usePracticeActions`; the panel renders state. Both remain below 250 lines.

The audit retained working capture/acknowledgement/lifecycle protocols and added missing combination coverage: actual interrupted quota capture → Settings/language navigation → a second tab's recovery attempt → offline completion → foreground reconciliation → exact original incomplete take → waiting update/reload, for both ordinary practice and a distinct-target dialogue. Round 4 subsequently disproved three claimed boundaries in R3/R4/R5/R6; the corrections and new evidence below supersede the incomplete pre-review coverage claims.
