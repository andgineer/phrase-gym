# Add your phrases

You can add phrases from your courses, notes or other learning material without filling in
individual phrase cards.

## Use Phrase Gym and Coach

If you already have a prepared material file, open **Add material**, choose the file or paste
its contents, and select **Import**. Coach prepares reference audio in the background.
Keep Phrase Gym and [Coach running](installation.md) until the import is confirmed as added.
If Coach is stopped, the request stays saved and waits for it. A failed import shows a reason
and a **Retry** action.

Coach currently prepares audio for supplied material; it does not yet extract phrases from
courses or notes. For that, use your personal AI agent.

## Ask your personal AI agent

Pass [the agent instructions](agent-add-phrases.md) to your AI agent; you do not need to read them.
Tell it where to find your
material and give it your Phrase Gym server address. It prepares the text, reuses suitable source
recordings or generates missing audio, and submits the complete material directly to Phrase Gym.
Once the server confirms the import, the phrases are immediately available for learning.
Ask the agent to report what was added and any material it could not finish.

The agent must be able to reach your server and prepare audio. If either is unavailable, resolve
that prerequisite with the agent before continuing.
