# Phrase Gym

Phrase Gym trains selected words in useful phrases, fixed expressions and prepared dialogues toward ready use.

The current source build provides a library, native-language explanations, language bookmarks, concept lookup and imported reference audio. Guided sessions, optional learner recording and spaced repetition are the next implementation phase.

Choose your native language on first launch. The interface can use that language or follow your learning language. Explanations always remain in your native language. Bookmark `/learn/en` or `/learn/sr` to keep language views separate.

Use **Find a phrase** to search wording or prepared concepts such as `greetings`. Opening a result shows its meaning and usage without grading it. Lesson links open the complete phrase list. Available **Reference** audio plays when requested; missing audio is shown explicitly.

See [installation](installation.md) to run the source build. For all local tools, run:

```bash
phrase-gym --help
```
